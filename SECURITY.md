# Beveiliging / Security

Meld een kwetsbaarheid in een repository van Oomny B.V. vertrouwelijk aan michael@oomny.nl, met
een beschrijving en zo mogelijk een reproductie. Gebruik geen publiek issue.

Report vulnerabilities in any Oomny B.V. repository privately to michael@oomny.nl. Please do not
open a public issue.
